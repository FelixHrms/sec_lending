# CLAUDE.md

## Branching

Always work directly on the `main` branch of this repository. Do not create any other branches and do not open pull requests. Commit and push to `main` only.

## Scope

Only do what the user asks for explicitly. Do not add extra changes, files, refactors or improvements that were not requested. When in doubt about whether something is in scope, leave it out and mention it briefly instead.
